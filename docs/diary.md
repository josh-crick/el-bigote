# El Bigote Project Diary

A chronological record of the development journey.

---

## 2026-08-01 - Project Started

The El Bigote website project began with the goal of creating a modern, high-quality website for a Mexican street food and cocktail venue in Basingstoke.

The project is being approached as a professional development project, focusing on good architecture, documentation, and maintainability, and learning modern web development practices.

Completed:

- Created Next.js application
- Configured TypeScript
- Configured Tailwind CSS
- Initialised Git repository
- Connected GitHub repository
- Deployed inital application to Vercel

Key Decisions:

- Use Next.js rather than a traditional website builder.
- Prioritise learning modern web development.
- Use a professional development workflow with version control and continuous deployment.

---

## 2026-08-03 - Architecture & Foundations

The project moved from initial setup into establishing the foundations for a maintainable codebase.

Completed:

- Created initial component architecture
- Established separation between layout, sections, and UI components
- Reviewed project structure and develpoment workflow

Key Decisions:

- Build using reusable components.
- Establish foundations before visual development.
- Prioritise maintainability and clear organisation.
- Avoid adding unnecessary complexity or tooling.
