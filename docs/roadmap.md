# El Bigote Website Roadmap

## Project Goal

Create a modern, fast, and visually distinctive website for El Bigote, a Mexican street food and cocktail venue based in Basingstoke.

The website should communicate the atmosphere of the venue while making it easy for customers to discover the menu, location, opening hours, and brand story.
